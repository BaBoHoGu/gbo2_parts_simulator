GBO2 커스텀 파츠 시뮬레이터 (오프라인)
========================================

■ 실행 방법
  dist 폴더 안의 gbo2-simulator.html 을 브라우저(크롬·엣지 등)로 열면 바로 실행됩니다.
  인터넷 연결이 필요 없습니다.

  · 편하게: run.bat 을 더블클릭하면 "업데이트 확인 → (있으면 반영) → 자동으로 열기" 까지 한 번에.
    변경이 없으면 수 초 만에 그대로 열립니다. (PowerShell 우클릭 필요 없음 — 그냥 더블클릭)

■ 주의
  이 폴더의 파일·폴더 구성을 그대로 두세요.
  특히 dist\gbo2-simulator.html 과 dist\images 폴더는 반드시 함께 있어야 합니다.
  (images 폴더가 없으면 기체·파츠 그림이 안 나옵니다)


■ 모바일(안드로이드)에서 쓰기
  이 폴더 최상위의  모바일-앱.apk  파일을 폰으로 옮겨 설치하면 앱으로 실행됩니다.
  (설치 시 "출처를 알 수 없는 앱" 허용이 필요합니다. 완전 오프라인·무권한으로 동작하고,
   저장한 구성·즐겨찾기는 앱에 그대로 유지됩니다. 덮어쓰기 설치해도 데이터는 보존됩니다.)

  · 참고: PC 에서 update 로 데이터를 새로 받아도, 폰의 APK 는 자동으로 갱신되지 않습니다
    (폰에는 APK 빌드 도구가 없기 때문). 최신 데이터가 반영된 새 APK 가 필요하면
    새 배포본의  모바일-앱.apk  를 다시 설치하세요.


■ 최신 데이터로 업데이트하기  (신규 기체·파츠·밸런스 반영)
  update.ps1 을 실행하면 gbo2.jp / 일본 위키에서 새로 추가·변경된
  기체·파츠·무장을 자동으로 받아 gbo2-simulator.html 을 다시 만듭니다.

  실행 방법:
    1) update.bat 을 더블클릭하면 됩니다. (가장 간단 — PowerShell 우클릭 불필요)
       또는 update.ps1 우클릭 → "PowerShell에서 실행", 또는 PowerShell 에서:  .\update.ps1
    2) 새 데이터가 있으면 자동으로 받아 반영하고, 없으면 "이미 최신" 이라고 알려줍니다.
    3) 끝나면 gbo2-simulator.html 을 새로고침(또는 다시 열기) 하세요.

  · 무엇이 바뀌는지 먼저 보고 싶으면(반영 안 함):  .\update.ps1 -Check
  · 업데이트에는 인터넷 연결이 필요합니다. (평소 시뮬레이터 실행은 불필요)
  · node 는 이 폴더의 node 폴더에 함께 들어 있어 따로 설치할 필요가 없습니다.

  ※ 처음 보는 기체는 한글명 사전에 없어 일본어 이름으로 표시될 수 있습니다.
     (성능·무장 계산은 정상)


■ 주요 기능
  · 기체 선택 → 파츠 적용 (강화 단계·확장 스킬·레벨 전환)
  · 성능 계산 (원본 사이트와 동일, 상한·증가분 표시)
    - 맨 아래 "내구 지표" = 피해 종류별 실효 HP (내성이 높을수록 큼)
    - 사격/격투 보정은 상한이 늘면(사격보정확장 등) 늘어난 만큼 피해에 반영됩니다
  · 무장 정보 (위력·리로드·누적치, 파츠·스킬·자세 보정 반영)
    - 격투 무장은 방향별(N격/횡격/하격)·연격 피해와 상태(헤비어택·최대출력) 표시
    - 조사·산탄·동시발사 무장은 전탄 명중 총 피해(×N)를 함께 표시
  · 기체 스킬 발동 토글 (바이오센서·ZERO 시스템 등)
  · 사격 자세/스코프 토글
  · 자동 구성 — 화면 중앙에 후보 카드로 표시, "더보기"로 최대 10개까지
    (가중치·확장 스킬을 안 정하면 방향·확장까지 알아서 골라 줍니다)
  · 저장 / 저장 목록 — 구성에 이름을 붙여 여러 개 저장하고,
    저장 목록에서 파츠·스탯·내구 지표 요약을 카드로 보며 불러오기·이름변경·삭제
    (공유/가져오기 버튼으로 JSON 복사·붙여넣기도 가능)
